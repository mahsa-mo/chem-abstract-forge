# ChemSketch AI

یک وب‌اپلیکیشن به نام "ChemAbstract" (یا نامی که خودت دوست داری) بساز که به 

پژوهشگران شیمی کمک می‌کند از روی متن مقاله یا شرح واکنش شیمیایی، یک چکیده 

تصویری (Graphical Abstract) استاندارد علمی تولید کنند.

## هدف و مخاطب

مخاطب اصلی، پژوهشگران و دانشجویان تحصیلات تکمیلی رشته شیمی هستند که می‌خواهند 

برای مقاله‌شان به سرعت یک تصویر خلاصه‌ی گرافیکی حرفه‌ای بسازند.

## زبان و بین‌المللی‌سازی (خیلی مهم)

- سایت باید دو زبانه باشد: انگلیسی و فارسی

- زبان پیش‌فرض هنگام باز شدن سایت باید انگلیسی (English) باشد

- یک دکمه/سوییچ زبان (Language Switcher) در هدر سایت قرار بده که کاربر بتواند 

  بین English و فارسی جابه‌جا شود

- وقتی زبان فارسی انتخاب شد، جهت کل صفحه باید به RTL تغییر کند و وقتی انگلیسی 

  است، LTR باشد

- تمام متن‌های رابط کاربری (دکمه‌ها، عنوان‌ها، پیام‌های خطا، placeholder ها) 

  باید در هر دو زبان ترجمه شده باشند، نه فقط بخشی از سایت

- فونت مناسب برای هر دو زبان انتخاب کن (یک فونت لاتین خوانا برای انگلیسی، 

  و یک فونت فارسی خوانا مثل Vazirmatn یا مشابه برای فارسی)

- ساختار کد باید طوری باشد که اضافه کردن زبان‌های بیشتر در آینده (مثلاً عربی) 

  ساده باشد (یک فایل/سیستم مدیریت ترجمه‌ی جدا از UI)

## طراحی و رابط کاربری

- طراحی مدرن، تمیز و علمی/آکادمیک؛ نه شلوغ و نه رنگارنگ بیش از حد

- پالت رنگی آرام و حرفه‌ای (آبی تیره، سفید، طوسی روشن، با یک رنگ تاکیدی مثل 

  فیروزه‌ای یا بنفش کم‌رنگ)

- طراحی responsive و کاملاً موبایل‌فرندلی، در هر دو حالت RTL و LTR

- انیمیشن‌های ظریف و حرفه‌ای هنگام لودینگ (نه اغراق‌آمیز)

- حس اعتماد و دقت علمی القا کند، نه یک اپ سرگرمی

## صفحه اصلی باید شامل این‌ها باشد

1. هدر ساده با لوگو/نام سایت، یک جمله کوتاه توضیح‌دهنده، و سوییچ زبان 

   (EN / فا) در گوشه‌ی هدر

2. یک کادر متنی بزرگ برای پیست کردن متن مقاله یا شرح واکنش شیمیایی 

   (placeholder راهنما داشته باشد که چه نوع متنی مناسب است)

3. یک دکمه واضح و برجسته "Generate Graphical Abstract" 

   (یا معادل فارسی‌اش وقتی زبان فارسی انتخاب شده)

4. حین پردازش، یک نشانگر لودینگ حرفه‌ای با پیام‌های متغیر مثل 

   "Analyzing chemical reaction..." نمایش داده شود

5. کادر نمایش تصویر خروجی، با دکمه دانلود (فرمت PNG)

6. یک بخش کوچک پایین صفحه که توضیح دهد این نسخه اولیه (بتا) است و از 

   کاربر بازخورد می‌خواهد

## محدودیت‌های مهم فاز اول (فقط همین‌ها، نه بیشتر)

- بدون سیستم لاگین/ثبت‌نام در این مرحله

- بدون صف پردازش پیچیده یا مدیریت کاربران همزمان زیاد

- بدون دقت ساختار مولکولی تخصصی (RDKit) — فعلاً فقط تولید تصویر کلی کافی است

- محدودیت تعداد استفاده رایگان: هر کاربر (بر اساس session یا IP) حداکثر ۵ بار 

  در روز بتواند تصویر تولید کند، و پیام مناسب (به زبان انتخابی کاربر) بعد از 

  رسیدن به سقف نمایش داده شود

## نکات فنی مهم

- کد را با تکنولوژی استاندارد بنویس (React + Next.js ترجیحاً)، بدون وابستگی 

  به قابلیت‌های اختصاصی که فقط روی یک پلتفرم خاص کار کنند، چون قرار است 

  بعداً این پروژه به یک سرور دیگر منتقل شود

- برای مدیریت چندزبانگی از یک روش استاندارد مثل next-intl یا i18next استفاده کن

- بک‌اند باید به سادگی قابل جایگزینی باشد (کد تمیز، جدا از UI)

- برای تولید تصویر، یک endpoint API جدا بساز که بعداً بتوان به سادگی سرویس 

  هوش مصنوعی پشت آن را عوض کرد

- از Supabase برای ذخیره‌سازی ساده (اگر لازم شد، مثل شمارش استفاده روزانه) 

  استفاده کن

فقط همین نسخه فوق‌ساده را بساز؛ ویژگی‌های پیشرفته‌تر در مراحل بعدی اضافه 

خواهند شد.
